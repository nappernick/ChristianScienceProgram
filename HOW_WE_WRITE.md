# How We Write and Build

A working method for *The Scrolls Beneath the Sea*: principles, rules, tests, and ways of getting unstuck.

## Principles

1. **The Bible is the book.** Chapters exist to carry a reader into it. A scene that is not moving toward built material is circling.
2. **Flow outranks devices.** A chapter is judged by what it does for the whole, not by how much it contains.
3. **The object is a gift. People supply the harm.** Nothing the artifact does is ever the threat.
4. **The far timeline is made of fossils.** Every custom on the ship is a real 2075 fact worn into another shape.
5. **Restraint is the voice.** The narrator sees, measures, and goes quiet.
6. **People are grounded before they are used.** Each person has a psychology, an economy, a body and a place in time, worked out in their folder. What they do in a scene follows from those. If a choice cannot be traced to the folder, either the scene is wrong or the folder is incomplete, and one of them gets fixed.

## Rules

| Rule | Reason |
| --- | --- |
| Place every Miriam beat on her arc before writing it | She shares by instinct early and withholds only after failing to be understood. A scene that gets this wrong breaks the engine of the book |
| Expertise must be load-bearing | If the scene plays the same with a character's job swapped out, the scene is not using the character |
| Every figure is computed or hedged | Depth, pressure, sound speed, temperature, dates, lag. One wrong number costs the reader's trust in all of them |
| The narrator never knows the future | Foreknowledge drains tension and leaves the close-third voice |
| A new person gets History, Philosophy and Flaws | A flaw needs a cause and a job. Without the cause it is a quirk; without the job it is decoration |
| A new custom gets its source, its mutation and its pressures | Lore without a lineage reads as invented. Lore with one reads as found |
| Every invention is listed where it can be overruled | Canon has one owner |
| Lengths are counted | Estimates of one's own output run long |

## Heuristics

- **Boring is a tool.** Placid, procedural time makes the next event land and makes a surprise a surprise. Spend it deliberately and stop before it becomes the chapter.
- **Some threads go nowhere on purpose.** A promising character or plot point that turns out dull, or simply stops, makes the world larger than the plot and keeps the reader from predicting by convention. It has to be chosen, it has to be rare, and it must never be a thread the book's main questions depend on. The dead end should be plausible in hindsight: the world was busy with something else.
- **Wonder before fear.** A reader has to want a thing safe before its danger means anything.
- **Data first, then sight.** The rendering before the porthole. The spectrum before the conclusion.
- **Give one answer and withhold one** per chapter, and know which is which before starting.
- **Friction only where the story has it.** Two people who agree, facing something large, is a scene.
- **Prefer the mechanical cause.** Buoyancy, pressure, sound. If a wonder can be passive, it is stronger passive.
- **Put a true thing in an inconvenient mouth.** The correct objection is more interesting from someone unlikable.
- **A person is added for the story's reasons,** never to complete a pattern.
- **A time skip must change what the present scene means.** Otherwise cut it.
- **Name a thing once.** Circling a feeling with negations is a tic.
- **Invent less than seems needed.** Each new name is a debt.

## Tests to run on a scene

| Test | Question |
| --- | --- |
| Trace | For each choice a person makes: which line in their folder does it come from? |
| Swap | Replace a character with anyone else aboard. Does the scene change? |
| Fossil | For a ship detail: what was it in 2075, and what wore it down? |
| Passive | Did the object act? If so, can water, rock, or a person do that work instead? |
| Clock | Is anything running out? If not, is the stillness on purpose? |
| Two columns | What did this chapter give the reader, and what did it keep? |
| Arc | Where is Miriam on the Bible's line from sharing to withholding, from certainty to doubt? |
| Hostile reader | Would an oceanographer, a linguist, or a theologian stop reading here? |
| Voice | Could this line be assigned to its speaker without a tag? |
| Cut | Remove the scene. What breaks later? If nothing, is it a deliberate dead end or an accident? |
| Herring | For a planned dead end: what did the reader expect, and is the letdown itself the point? |

## When something is not working

| Symptom | Approach |
| --- | --- |
| The scene is flat | Find what each person wants and will not say. If nothing, the scene may be a paragraph |
| Tension feels manufactured | Trace it to a physical limit or a human want. If it traces to neither, remove it |
| A reveal has no weight | Add quiet before it, not emphasis on it |
| Exposition is heavy | Give it to the character who would be bored by it, during a task |
| A character is interchangeable | Run the swap test, then find the thing only they would notice |
| Lore feels made up | Write its lineage. The awkward leftover detail is usually what makes it real |
| The chapter is all setup | Move one payoff forward from the next chapter |
| The chapter is all event | Insert a stretch where nothing happens and people do their jobs |
| A scene contradicts the Bible | The Bible wins. Keep the scene for the point in the arc where it becomes true |
| Two timelines feel unrelated | Find the one fact that appears in both, changed |
| The science is uncertain | Compute it, and if it cannot be computed, have a character be unsure in the text |

## Procedures

**A chapter**

1. State in a few lines where it goes, what it gives, what it keeps, and which questions it opens.
2. Mark the Bible passages it draws on and reread them.
3. Draft. If more than one draft, each gets a different plan, not a different volume.
4. Run the tests.
5. Write the files for anything new.
6. List what was invented.

**A person**

A folder holds eight files. The last one is derived from the others.

| File | What it answers |
| --- | --- |
| History | What happened to them, in order |
| Philosophy | What they believe and how they would defend it |
| Flaws | The flaw, where it comes from, and what it makes happen |
| Psychology | The wound, what was built on it, how they behave under stress, what they cannot do |
| Economics | Who pays them, what they owe, what they own, who depends on them, and so what they can afford to say |
| Body | Age, senses, injuries, what the setting does to them physically, and what that lets them perceive or keeps them from |
| Timeline | Dated events, and what is running out |
| Choices | Situation, what they do, and which of the above it follows from. Ends with the line they will not cross |

For a character who already exists in the Bible or the chapters, each file separates what is fixed from what is proposed, and lists what the source leaves open.

**A piece of lore**

1. The fact as it happened.
2. Who first told it, and what they needed from it.
3. Each hand it passed through, and what that hand could not afford to keep.
4. The practical pressure that fixed its final form.
5. The true detail that survived by accident.
6. Who still knows the original, and as what.

**A number**

1. Compute it from first principles.
2. Check the units.
3. Use it once, plainly.

## Canon

Changes to the artifact's properties, to who Miriam is, or to the history of the war belong to the author. Everything else is decided, used, and listed.
